Upload a file as a stream

The raw request body is piped into Ergosfare. A pre interceptor validates the file section and hands its first chunk and open parser to the handler, which continues writing to disk without buffering the entire file.

Choose a file to get started.


Progress shows bytes sent by the browser. Once disk writes finish, the server returns the file size, chunk count, declared MIME type and SHA-256 digest. Files are stored under examples/e2e/upload with unique names; a companion JSON file preserves their metadata. MIME is reported by the client, not detected from the contents. Cancelled uploads have their partial files removed.
